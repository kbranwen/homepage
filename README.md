# Homepage

A polished personal homepage and résumé template built with HTML and CSS.

## Overview
This project provides a clean, modern layout for presenting professional experience, education, and skills in a simple and visually appealing format.

## Features
- Clean and responsive design
- Professional resume-style layout
- Easy to customize with your own content

## Usage
Open the project in a browser to view the homepage, or edit the HTML and CSS files to personalize the content and styling.
